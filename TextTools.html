How Do I Use This Tool?

Exporting:

  • Acquire the .bytes file from your game. (On Steam, you can find it in the game's StreamingAssets directory, on Switch you must extract the RomFS)
  • Select a game from the dropdown menu. If you don't see your game, Select "Other" and specify the character array. (Character arrays are different for each game and may be located in different places)
  • Click Browse and select the .bytes file you want to export.
  • Click the export button to process the file.
  • Click download as .txt or .csv to download the exported file in your preferred format.

Importing:

  • After exporting your text, you can edit it in a text editor or spreadsheet program.
  • When you're ready to import your changes, select the game from the dropdown menu
  • Click Browse to select your edited .txt file. (.csv support coming soon!)
  • Click the import button to process your files.
  • Click download to download the game formatted file.
  • Replace the original .bytes file in your game's directory with the downloaded file. (Or, if on Switch, place it in the appropriate mod directory)

Why would I select "Other" in the Game Selector?/What is a Character Array?

"Other" allows you to specify a custom character array if your game is not listed. A character array is a list of characters that the game recognizes. It is used to convert the text in the game into a format that can be read and edited by humans. Each game has its own character array, which may be located in different places within the game's files.

Why is .csv supported for export and but not for import?

.csv support is planned for a future update. Currently, only .txt files are supported for import. If you are working from a .csv file, you can export the final translation column as a .txt file delimited by newlines and import that instead.

Why can I not select download after exporting?

The file you provided is likely not a valid .bytes file and the tool failed to parse it. Please ensure you are using a valid .bytes file from the game you selected and try again. Enhanced error handling and reporting is planned for a future update.
